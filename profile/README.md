<br>

<h2 align="center">
  <a href="https://github.com/if-then-nvim/if.nvim">
    <picture>
      <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/if-then-nvim/if.nvim/main/assets/logo-dark.svg">
      <img src="https://raw.githubusercontent.com/if-then-nvim/if.nvim/main/assets/logo-light.svg" height="44" alt="if.nvim">
    </picture>
  </a>
</h2>

<p align="center">
  A hand-built UI layer — statusline, bufline and dashboard — and a theme
  engine that compiles its highlights to Lua bytecode.<br>
  The architecture follows NvChad's; the code is written from scratch.
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/if-then-nvim/.github/main/assets/hero.webp" width="100%" alt="if.nvim">
</p>

<p align="center">
  Start from <a href="https://github.com/if-then-nvim/if-starter">if-starter</a>,
  which bootstraps lazy.nvim and pulls the distribution in as a plugin,<br>
  so <code>:Lazy update</code> upgrades it without touching your own config.
</p>

<br>

<h2 align="center">
  <a href="https://github.com/if-then-nvim/if.db">
    <picture>
      <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/if-then-nvim/if.db/main/assets/logo-dark.svg">
      <img src="https://raw.githubusercontent.com/if-then-nvim/if.db/main/assets/logo-light.svg" height="44" alt="if.db">
    </picture>
  </a>
</h2>

<p align="center">
  A database client that shells out to the database's own CLI. No driver to
  install, nothing to compile, no daemon —<br>
  if you can reach a database from your shell, if.db can reach it too.
  PostgreSQL, MySQL, MariaDB and SQLite.
</p>

<p align="center">
  <img src="https://raw.githubusercontent.com/if-then-nvim/if.db/main/screenshots/hero.webp" width="100%" alt="if.db">
</p>
